# Doomino's Pizza Lab

Fictional school pizza website for a web design / PHP course assignment.

**Doomino's** is an original student brand name (not Domino's). Logo and copy are made for class use only.

## Pages

| Page | File |
|------|------|
| Home | `index.html` |
| About | `about.html` |
| Menu / Shop | `shop.html` |
| Contact | `contact.html` |
| Products | `products/*.html` |

## Stack

- HTML5
- [Tailwind CSS](https://tailwindcss.com/) via CDN
- Theme: `css/tailwind-config.js`
- Extras: `css/styles.css`
- Fonts: **Oswald** + **Nunito Sans**

## Brand

- Name: **Doomino's** (fictional)
- Logo: student SVG — red half with **two** dots on top, blue half with **one** dot on bottom
- Colors: blue `#006491`, red `#e31837`, cream `#f7f4ef`

## Local preview

```bash
cd labs/pizza
php -S localhost:8080
```

Open http://localhost:8080/
