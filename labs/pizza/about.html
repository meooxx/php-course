About This Lab

A fictional school pizza brand

Doomino's is an original name for this coursework site. The layout practices common pizza-ordering patterns (blue header, cream background, delivery / carryout choice, menu cards) and is built with Tailwind CSS.

This is not a real restaurant and is not affiliated with Domino's or any other pizza chain. The logo and brand name are student-made to avoid trademark use.
